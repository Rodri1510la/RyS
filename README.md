# Rod y Silv - Sitio Web Romántico 💕

Un sitio web especial creado con amor para celebrar la relación entre Rod y Silv.

## 🌟 Características

- **Página principal** con carta romántica interactiva
- **Galería de fechas importantes** y momentos especiales
- **Sección de mensajes** para comunicación
- **Páginas temáticas** para diferentes ocasiones:
  - Cumpleaños
  - Aniversario  
  - San Valentín
  - Navidad
  - Y más...

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3 con animaciones
- JavaScript vanilla
- SCSS para estilos avanzados
- Responsive design

## 📱 Compatibilidad

- ✅ Navegadores modernos (Chrome, Firefox, Safari, Edge)
- ✅ Dispositivos móviles y tablets
- ✅ Optimizado para diferentes tamaños de pantalla

## 🛠️ Instalación y Desarrollo

1. Clona el repositorio:
```bash
git clone https://github.com/Draigo15/RodySilv.git
```

2. Navega al directorio:
```bash
cd RodySilv
```

3. Instala las dependencias (opcional para desarrollo):
```bash
npm install
```

4. Inicia el servidor de desarrollo:
```bash
npm start
```

## 🌐 Deployment

Este sitio está configurado para desplegarse automáticamente en Azure Static Web Apps cuando se hace push a la rama `main`.
